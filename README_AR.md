# متجر النقاط — النسخة الجاهزة للاستضافة

هذه الحزمة تحتوي واجهة الزبون + لوحة المدير + Backend + قاعدة SQLite.

## 1) الرفع
ارفع **كل محتويات هذا المجلد** إلى مجلد مشروع Node.js في الاستضافة.

## 2) تثبيت المكتبات
من Terminal الخاص بالاستضافة شغّل:

```bash
npm install
```

## 3) متغيرات البيئة
أنشئ ملف `.env` أو أضف Environment Variables من لوحة الاستضافة:

```text
NODE_ENV=production
PORT=3000
SESSION_SECRET=ضع_سر_عشوائي_طويل_جداً
```

إذا كانت الاستضافة تحدد PORT تلقائياً، اترك PORT كما هو في إعداداتها.

## 4) التشغيل
```bash
npm start
```

## بيانات المدير الافتراضية
- اسم المستخدم: `admin`
- كلمة المرور: `123456`

غيّر كلمة المرور بعد أول دخول قبل الاستخدام الفعلي.

## قاعدة البيانات
يتم إنشاء `store.db` تلقائياً أول تشغيل. لا تحذف الملف إذا كان المتجر مستخدماً.

## فحص الخدمة
بعد التشغيل:

`/api/health`

إذا ظهر `ok: true` فالسيرفر يعمل.

## ملاحظة مهمة للاستضافة
يجب أن تكون الاستضافة تدعم **Node.js** وتشغيل Express، وليس استضافة HTML/PHP فقط.

الصور تُحفظ داخل قاعدة البيانات كبيانات صورة، لذلك يفضّل عدم رفع صور ضخمة.
